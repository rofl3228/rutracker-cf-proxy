## Description

Adds RuTracker CF Proxy to the community train.

RuTracker CF Proxy lets Prowlarr use RuTracker, which sits behind a Cloudflare managed challenge.
Prowlarr's built-in FlareSolverr/Byparr integration replays the solved request with its own .NET HTTP client,
and Cloudflare rejects that replay (the clearance is bound to the User-Agent, the browser TLS fingerprint and the IP).
This proxy takes only the `cf_clearance` cookie and User-Agent from Byparr and sends the real requests
(login, search, .torrent download) with a matching browser fingerprint. Search results are cached briefly.

It ships a Cardigann indexer definition for Prowlarr with Radarr/Sonarr-friendly release titles.

## Special Notes

- Requires a running Byparr (available in this catalog). Byparr and this app must reach the internet from the same public IPv4 address.
- The app has no web UI; `/health` is used for the health check.
- **Prowlarr Integration (optional, disabled by default):** a one-shot helper container writes the indexer
  definition into a user-selected host path and exits. The intended setup is a dedicated dataset that the user also
  adds to Prowlarr as Additional Storage at `/config/Definitions/Custom`. The app does not touch Prowlarr's own
  storage. If Prowlarr's URL and API key are provided, it calls Prowlarr's `IndexerDefinitionUpdate` command so the
  definition is reloaded without a restart. Happy to drop the API call or the whole helper if it does not fit the
  catalog policy.
